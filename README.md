# Kakarot Extension

A repository for paperback that includes both manga and comic extensions

## 📚 Available Sources

- Batcave
- Elftoon
- GodaComic
- Hentai2Read
- MangaBall
- MangaBuddy
- MangaCloud
- NHentai
- NovelFire
- ProjectSuki
- ReadAllComics
- ReadComicsOnline

## 🚀 Installation

1. Open Paperback
2. Add this repository using [this link](https://karrot0.github.io/KakarotExtension/0.9/stable/)
3. Install and enjoy reading!
